# OpenTour Specification (draft)

The v0.1 draft is being written here. Structure:

- `package.md` — container layout (a zip-based `.otour` package with a `manifest.json`)
- `manifest.md` — the manifest schema: tour metadata, scenes, links, hotspots, floor plans
- `assets.md` — panorama and 3D asset requirements, chunking and level-of-detail
- `accessibility.md` — required accessibility metadata
- `versioning.md` — versioning and compatibility rules

Nothing here is final. Open an issue if you produce or consume virtual tour data and the model
does not fit your case.
